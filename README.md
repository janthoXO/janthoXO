## Hi there 👋

I'm Dennis, a CS student at the Technical University of Munich. I like building things end to end, from distributed backends to small tools that fix my own everyday annoyances.

### What I'm working on

- **AI for learning:** [AetioMed](https://github.com/janthoXO/AetioMed) generates synthetic patient cases from ICD-11 for medical education, with anamnesis and a blinded diagnostic workup. [VocalisCast](https://github.com/janthoXO/VocalisCast) produces language-learning podcasts that teach new words in context, using a local or hosted LLM and TTS.
- **Distributed systems:** [convergeKV](https://github.com/janthoXO/convergeKV) is a leaderless AP key-value store in Go. It uses CRDTs for conflict resolution, Merkle trees for anti-entropy and gossip for membership.
- **Education tooling:** I contribute to [Scorpio](https://github.com/EduIDE/scorpio), the Theia/EduIDE infrastructure for the [Artemis](https://github.com/ls1intum/Artemis) learning platform.
- **ML and data:** [sentiment-analysis-recommender](https://github.com/janthoXO/sentiment-analysis-recommender) scores US stock news from bearish to bullish with FinBERT. [MixMansion](https://github.com/janthoXO/MixMansion) sorts Spotify songs into playlists by vibe, using genre, mood and lyrics analysis.
- **Small tools:** [KlangLadder](https://github.com/janthoXO/KlangLadder) is a macOS menu bar app that switches audio devices by priority. [pokemon-tcg-pocket-mcp](https://github.com/janthoXO/pokemon-tcg-pocket-mcp) is an MCP server for searching Pokémon TCG Pocket cards.
